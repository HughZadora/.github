# .github

Account-level GitHub community health files shared by repositories owned by this account.

This repository is intentionally narrow. It provides GitHub-native defaults such as contribution,
issue, pull-request, security, support, and related community files. It does **not** define a global
repository standard, project schema, shared checker, build system, or cross-repository engineering
canon.

Agent governance is provided by `HughZadora/agent-charter`. Each project keeps its own repository
truth, native manifests, CI, verification commands, lifecycle, and project-specific instructions.
